# 九宮格書法與生字作業簿產生器（花蓮縣書法學習網 功能升級版）

本網站為參照「花蓮縣書法學習網」之九宮格練字簿與格子簿所全新重製之現代化網頁應用，並特別強化**「匯出高畫質圖檔 (PNG / JPG / ZIP / 剪貼簿)」**與多種排版功能。

---

## 🌟 核心特色與功能

### 1. 兩大練習簿模式
*   🖌️ **書法大字練習簿**：
    *   經典 2×3（每頁 6 字，同花蓮縣書法學習網風格）、2×4（8 字）、2×2（4 字）、1×4（直幅）、3×4 等大字版面。
    *   左下角自動排版**原句直排對照欄、標準台灣注音符號（含聲調）與大寫中文頁碼**。
    *   支援由右向左直排（傳統書法）與由左向右直排。
*   📝 **生字九宮格作業簿（格子簿）**：
    *   支援標準作業簿規格：6×10（60 格）、5×7（35 格）、7×12（84 格）、8×12 等，亦可任意自訂欄列數。
    *   三種填充練習模式：
        1.  **全文連續填滿**：適合抄寫心經、唐詩宋詞、千字文。
        2.  **生字臨摹（範例+描紅+空格）**：每個生字先給 1 格黑字示範、1 格雙鉤/淡灰描字，後續為空白格供臨摹。
        3.  **每字一行**：首格示範，後續描寫與空白練習。
    *   可自訂作業簿頁首欄位（學校、班級、座號、姓名、成績評分方格）。

### 2. 多樣格線選擇
*   **新九宮格**（林岳瑩標準模式，支援 1:1:1 標準均等與 3:4:3 中宮緊縮專利比例，可疊加中心十字線）。
*   **田字格**（經典十字虛線）。
*   **米字格**（十字虛線 + 對角斜線）。
*   **井字格**（傳統 3×3 等分九宮格）。
*   **回字格**（同心內外方框）。
*   **空白方格**（乾淨純外框）。
*   格線色彩任選：經典硃砂紅、玄墨黑、翠竹綠、青花藍、鉛灰色或任意自訂色彩。
*   線條粗細、虛線/點線/實線樣式、濃度隨心調配。

### 3. 多種字體呈現方式
*   **實心黑字**：清晰規範示範。
*   **雙鉤空心字**：極佳的外框描摹練習。
*   **描紅淡灰字**：浮水印淺灰底字，可直接覆蓋描寫。
*   **虛線描邊字**：結構指引輔助。
*   內建台灣標準楷體（標楷體、全字庫楷書、思源宋體），更支援**「自訂本機字型上傳 (.ttf / .otf)」**，任何名家書法字型都能一鍵套用！

### 4. 🚀 完整圖檔匯出功能（符合使用者核心需求）
*   🖼️ **匯出 PNG 圖檔**：可設定 1x（網頁用）、2x（高清 2100×2970）、3x（300 DPI 印刷級 3150×4455），單頁獨立下載，完全不失真！
*   🖼️ **匯出 JPG 圖檔**：高品質白底 JPG，方便傳送或備份。
*   📦 **打包全部圖檔 (ZIP)**：多頁練習帖時，一鍵打包全套頁面圖檔為 ZIP 檔一次下載！
*   📋 **複製圖檔到剪貼簿**：一鍵將當前頁複製至剪貼簿，直接在 LINE、Word、PowerPoint 貼上（Ctrl+V）！
*   🖨️ **高畫質列印 / 另存為 PDF**：內建專用列印樣式，100% 呈現格線與背景，無需擔心瀏覽器預設不印背景的問題。

### 5. 內建豐富範本庫
*   **結構教學組（花蓮書法網精選）**：橫一長、撇捺開張、長鉤挺拔、頂天立地、出頭伸腳、左小右大、左右等大、左大右小、均間結構。
*   **經典詩詞**：楓橋夜泊、登鸛雀樓、靜夜思、春曉、江雪、尋隱者不遇、相思、遊子吟、憫農、黃鶴樓。
*   **抄經與啟蒙長篇**：般若波羅蜜多心經（全文 260 字）、千字文、三字經、弟子規、朱子治家格言。

## 💻 如何開啟使用？

1. 直接在資料夾中雙擊點開 **`index.html`**，即可在 Chrome、Edge、Safari 或 Firefox 等任何瀏覽器中順暢使用。
2. 本工具完全基於前端 HTML5 Canvas 打造，**完全不需安裝後端伺服器或依賴任何指令**，離線斷網亦可隨時產生與匯出圖檔！
